Kenapa gesture control?

Sistem Pengenalan Isyarat Tangan (Hand Gesture Recognition) mendeteksi dan mengklasifikasikan gerakan tangan secara real-time dari kamera biasa.

⚡

Real-time

Model Machine Learning membaca gestur langsung dari kamera dan menerjemahkannya menjadi perintah digital.

🧼

Touchless

Interaksi yang intuitif dan higienis, tanpa perlu menyentuh perangkat fisik atau layar.

🏠

Banyak kegunaan

Cocok untuk smart home, navigasi presentasi nirkabel, interaksi VR, hingga asisten bahasa isyarat.

Cara kerjanya

Tiga langkah dari model sampai robot bergerak.

Langkah 1

Muat model

Tempel link model Teachable Machine milikmu.

Langkah 2

Nyalakan kamera

Tunjukkan gesture, AI akan mengenalinya.

Langkah 3

Hubungkan robot

Sambungkan micro:bit, perintah terkirim otomatis.

Coba sekarang

Gunakan Chrome atau Edge agar kamera dan Bluetooth bisa berjalan.
